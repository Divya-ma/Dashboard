# Notes and helpers

| File | What it is |
|---|---|
| `neighbour_interpolation.py` | The worked, self-contained (numpy only) version of the Curve Kinks maths: how each point of a curve is predicted from its neighbours, the residual, the z-scores and the kink search. The app uses the same maths in `core/`; this copy is for reading and experimenting. |
| `../service/nssm_install.bat`, `nssm_uninstall.bat` | Register or remove the Windows service (README section 10). |
| `../tools/probe_api_codes.py` | Read-only probe for the API codes that were never confirmed (README section 12). |
| `../tools/healthcheck.py` | The Docker health check. |
| `../README.md` | Everything else: architecture, calculations, every page, storage, configuration, deployment. |
